# DEC-20260828-011 — 使用产品自有网盘目录名且不迁移旧目录

**状态：** 已采纳

## 决定

当前用户网盘中的备份根目录固定为 `MimiAppBakcup/`。该名称不使用平台品牌，目录下既有的快照、`_partial/`、`_trash/` 与 `_restore_exports/` 相对路径结构保持不变。

服务初始化时只创建或使用 `MimiAppBakcup/`。服务不迁移、合并、扫描、删除或修改旧 `LazycatAppBackup/` 目录。

## 理由

产品目录名应属于产品自身，避免非官方应用使用懒猫品牌。目录改名不应自动改动用户已存在的文件，因此旧目录由用户自行保留或处理。

## 边界与验证

- 不增加 `appvar.other.write`、宿主机挂载、跨用户参数或旧目录回退。
- 本地 Go/Vite 构建和 LPK 打包只能验证编译与封装；真实平台仍需确认新目录写入结果。
