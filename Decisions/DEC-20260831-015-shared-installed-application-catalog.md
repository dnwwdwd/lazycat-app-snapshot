# DEC-20260831-015 — Shared installed-application catalog

**状态：** 本地已实现；真实平台验证待执行
**关联需求：** `REQ-20260830-008`
**日期：** 2026-08-31

## 决定

管理员和普通用户都使用平台返回的全部已安装应用目录。`QueryApplication` 不传 `other_uid`，并将 `only_owner` 设为 `false`；返回的 `owner` 只作为平台元数据，不作为当前账号的目录过滤条件。

应用安装者与使用者可以不同。每个登录用户仍通过会话 `gateway_uid` 隔离自己的控制数据库、计划、任务、快照索引、审计和懒猫网盘写入；本决定不增加租户切换、跨租户控制库查询或目标应用写权限。

## 原因

懒猫平台中管理员安装的应用和普通用户安装的应用可以共同使用。此前普通用户使用 `only_owner=true` 并按 `owner == gateway_uid` 过滤，导致普通用户只能看到自己安装的 10+ 个应用，而管理员能看到全量 67 个应用，目录不一致。

## 实现边界

- 目录同步、探测和实例选择对所有已认证角色使用相同的全量范围。
- `appid`、`deploy_id`、`owner` 等必要字段仍必须存在，备份应用自身仍排除。
- appvar 源解析仍固定在运行时投影根目录，拒绝绝对路径、路径穿越和符号链接逃逸。
- 备份任务只接受当前会话目录中已同步的 `deploy_id`，归档只写入当前会话的网盘。

## 待验证

在真实懒猫设备分别使用管理员和普通用户登录，确认两者应用数量一致，并确认计划、任务、快照与网盘记录继续各自隔离。
