# DEC-20260826-005 — POC 对单实例目标只告警并继续验证

## Decision

本轮 POC 允许当前用户选择自己拥有的单实例目标应用。服务端完成租户校验、源目录校验、递归探测和一次手动只读快照；页面明确显示“共享 appvar 可能包含多个用户数据”的风险告警。单实例目标在扫描成功后仍返回 `BACKUPABLE`，因此可以验证真实平台的读取与快照链路。

V1 允许当前用户可见的单实例目标进入备份，但始终标记共享实例风险。用户首次手动备份或创建计划时必须确认该风险；快照 manifest 保存 `multi_instance=false` 和风险标记。该支持不表示单实例 appvar 已按用户拆分。

## Rationale

如果 POC 在看到 `multi_instance: false` 时提前停止，就无法验证用户要求的“选择应用、查看应用数据、执行一次手动快照”流程，也无法区分产品边界问题和平台 source resolver 问题。只读探测与快照仍受 `owner_uid == tenant_uid`、路径边界、源只读检查和无目标写权限约束；放宽不会引入跨用户查询、宿主机挂载或 `other_uid`。

## Validation boundary

单实例 POC 已验证当前平台能够为该目标提供可读取的源投影。验证结果不证明 appvar 已按用户拆分，因此 V1 必须保留风险提示和确认记录；平台、权限、投影或源解析器变化后，重新执行两用户回归。
