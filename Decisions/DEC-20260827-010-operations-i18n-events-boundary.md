# DEC-20260827-010 — 阶段 5 运营界面、事件与国际化边界

**状态：** 已采纳（本地实现）；真实平台证据待补

## 决定

阶段 5 在每个当前用户实例的控制库中新增告警、设置、审计记录和单调递增事件序列。所有记录继续保存 `tenant_uid`，读取和变更均由服务端按当前会话和容器 tenant 过滤。前端不提交或显示其他用户 UID、目标应用源路径、Token、Cookie 或租约信息。

服务端以 SSE 仅推送当前租户的聚合业务事件：批次、任务、快照、告警、存储和会话即将到期。事件不携带文件正文、源绝对路径或跨租户标识；浏览器在断线或事件间隙后用现有 REST 列表重新同步，不把 SSE 当作唯一事实来源。事件缓冲区只用于短时重连，重启后的权威状态仍来自 SQLite。

设置保存为受限的当前用户默认值。阶段 5 只开放已经被服务端使用或能安全展示的语言、时区、补跑、重试、保留、回收站宽限期和通知偏好；不开放宿主机路径、用户 UID、权限提升或未接入执行引擎的伪配置。告警以站内告警为主；可选 `user.notify` 未授权时不影响备份、计划或告警记录。

前端维护 `zh-CN` 与 `en-US` 文案。后端继续返回稳定错误码和安全参数，前端用错误码翻译提示；日期、容量和状态随当前语言格式化。当前语言持久化在当前浏览器，登录会话和业务表不保存浏览器私密数据。

## 后果

- 概览、告警、设置、任务/批次详情、计划向导和所有主菜单读取正式 API，不保留成功、进度、告警或配置变更的本地模拟逻辑。
- 自动生成的任务失败、快照校验失败、应用阻断状态和存储对账异常写入站内告警；用户操作、计划变更、任务状态和存储维护写入当前租户审计记录。
- API 增加 overview、alerts、settings、audit 和 events 契约。SSE 与通知权限需要在真实懒猫设备验证，不能用本地测试替代。
- 不实现跨用户审计、管理员查看、外部通知渠道、直接恢复、目标应用写入或后台自启动保证。
