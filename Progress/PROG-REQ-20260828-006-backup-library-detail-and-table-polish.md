## 本次实现

- 批次详情使用居中详情弹窗，进度、成功和失败合为紧凑摘要；从批次任务打开的任务详情在同一弹窗中切换，不再叠加第二层遮罩。
- 任务详情移除重复状态和长快照 ID 指标，改为应用、状态、关键时间、范围和执行记录的紧凑信息区。
- 计划页按“计划 / 最近执行”组织；任务中心按“当前或最近执行 / 任务历史”组织，顶部只保留运行、排队和失败计数。
- 快照详情将范围声明、实际归档、SQLite、跳过项、范围修订和完整性记录合并为“备份内容”，文件索引只默认显示前 30 项。
- 快照详情移除校验、导出和移入回收站入口，只展示创建时记录的完整性状态，并说明打开详情不会发起新校验。
- 服务端在快照列表和详情返回当前用户云端目录状态；前端展示 `MimiAppBakcup/<完整路径>`，目录缺失时明确提示，文件索引读取失败时保留快照元数据。
- 设置页“错过后补跑”改为左侧名称、右侧开关的控件；全站表格表头统一提升字号、底色和边界层次。
