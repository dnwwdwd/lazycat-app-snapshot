# REQ-20260829-007 — 计划选择性备份范围

**类型：** 功能与体验改进  
**状态：** 本地实现完成；真实懒猫验证待执行  
**来源：** 2026-08-29 用户确认的选择性备份方案  
**进度记录：** `Progress/PROG-REQ-20260829-007-selective-backup-scope.md`

## 目标

计划中的每个应用目标可独立使用完整或自定义范围。自定义范围只接受当前用户应用数据根下的目录和单文件。任务和快照都保留入队时的范围修订，并显示声明范围与实际归档统计；范围修订和跳过记录仅作追溯，不进入默认详情。

## 验收条件

1. 完整备份覆盖数据根下全部可支持的普通文件与标准 SQLite；符号链接、特殊文件和 SQLite 伴随文件仍按安全规则跳过，快照仍标记为完整。
2. 自定义目录持续覆盖其当前子内容；目录内文件增减不会暂停。已选目录本身、已选单文件或源根失效、类型变化、不可读取时暂停整项多应用计划。
3. 计划运行前校验全部目标。范围失效时不创建可执行任务，已排队任务变为跳过，运行中任务可安全完成。
4. 重新保存范围会递增该目标范围修订，取消尚未启动的旧修订任务，清除暂停原因并重新计算下次运行时间。
5. 新建和编辑计划只显示完整和自定义范围。已有 `CORE` 记录可继续读取、执行和展示，但不在范围选择器中作为新选项提供。
6. 范围选择器、任务详情、快照详情、计划列表、告警与 V2 原型都说明完整/部分状态、失效原因与重新选择入口；计划列表用可读周期或 Cron 含义代替调度枚举，并提供查看、执行、暂停/启用和编辑图标操作。
7. 新建和编辑计划采用移动端可用的四步向导：先选择整个应用或选择性备份，再批量添加应用、逐个配置范围，最后设置计划并确认保存。不得把应用、范围和计划设置并列塞进同一工作台。
8. 自定义范围以可展开文件树呈现，父目录选择覆盖全部后代；目录、SQLite、配置、文档、图片、代码和普通文件使用不同图标及色彩提示。Cron 输入实时显示五段表达式的可读执行含义，并在格式或字段不合法时给出原因。

## 边界

- 立即备份固定为完整备份。
- 新建或编辑计划只保存计划本身，不在保存弹窗中立即入队；需要立即执行时从计划列表手动运行。
- 服务端只识别原相对路径不存在或类型变化；不搜索新位置，不自动迁移范围，不自动恢复暂停计划。
- 不接受绝对路径、`..`、越界符号链接、特殊文件和 SQLite WAL/SHM/journal 伴随文件。
- 不增加跨用户、宿主机、目标应用写入或 `appvar.other.write` 权限。

## 本地检查与真实设备证据

本地只执行 Go 构建、OpenAPI 类型生成、Vite 构建和差异检查。真实设备需覆盖目录失效、单文件改名、类型变化、更新范围取消旧任务、暂停与重新保存恢复，均限当前用户。
