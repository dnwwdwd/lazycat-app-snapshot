# REQ-20260901-013 — 概览图表与列表列宽优化

**类型：** 功能与体验改进
**状态：** 本地实现完成；真实平台验证待执行
**来源：** 2026-09-01 用户反馈
**进度记录：** `Progress/PROG-REQ-20260901-013-overview-chart-and-table-polish.md`

## 目标

- 首页“保护概览”图表使用当前租户 overview 接口返回的真实状态数量，不再使用固定比例。
- 图表支持鼠标悬停、点击和键盘选择，选中状态有明确反馈并展示对应数量。
- 应用页和备份库页不再单独展示部署实例列；`deployId` 仍保留在详情、筛选和后端关联中。
- 应用页数据库特征标签按内容自适应宽度，短标签不被拉伸为整列宽度。
- 固定 `package.yml` 版本 `0.1.0`，完成本地 LPK 重打包。

## 验收条件

1. 保护概览图表的每个扇区按 overview 的保护、待首次备份、数据库不支持、无数据及剩余状态数量计算；没有数据时显示空状态，不出现写死比例。
2. 鼠标悬停、点击或键盘聚焦扇区/图例时，选中扇区高亮，中心或辅助信息显示本地化状态和数量；控件具备可访问名称。
3. 应用表和备份库表移除“部署实例 / Deployment”表头和对应单元格，空状态 `colSpan` 与列数一致。
4. 数据库特征标签只占用自身内容所需宽度，并在窄屏表格中保持可读。
5. 只执行 Go 编译、Vite 构建、`git diff --check` 和 LPK 信息/lint 检查，不运行测试套件，不部署、发布或推送。

## 边界

- 不新增 API、数据库字段、权限或跨租户行为；图表数据只读取现有 `GET /api/overview`。
- 不删除 `deployId` 的详情、筛选、任务、快照和计划关联能力。
- 不改变备份、源数据只读、网盘写入和 `MimiAppBakcup` 存储边界。
