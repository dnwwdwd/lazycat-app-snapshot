## 范围

- 将 `designs/web.tsx` 作为正式界面的唯一视觉和页面结构来源；其 CSS 原文完整迁移到 `apps/web/src/styles.css`，不添加额外样式规则。

- 以 `deployId` 作为应用实例、计划目标、任务、快照和批量操作的前端关联键。
- 使用 REST API 和一条 SSE 订阅提供真实数据；事件在 1.2 秒内合并，断线 15 秒后重连。401 或身份不匹配回到 OIDC 登录。

- 重写 OIDC 登录页面，保留显式点击登录、回调、`return_to`、中英文和身份不一致提示。

## 已确认的界面边界

- 删除首次使用向导、总队列暂停/恢复、模拟性能指标、固定配额、固定活动、任务日志和阶段时间线、逐文件 SHA-256、应用运行状态和目录数量等无接口信息。
- 单实例手动备份只展示共享数据风险，用户点击后直接入队，不增加二次确认门槛。
- 存储占比使用 `archiveBytes / (archiveBytes + availableBytes)`；应用下次执行时间从关联且启用的计划推导，计划最近结果从真实批次推导。
- 设置仅提交服务端定义字段。状态、错误、日期和容量提供 `zh-CN` 与 `en-US` 显示。

- 范围查询变更时客户端重置游标，保存范围仍由服务端重扫并校验。
- 仅进行 Go 构建、OpenAPI 类型生成、Vite 构建和差异检查；不新增、修改或运行测试，不发布、部署、推送或创建合并请求。
