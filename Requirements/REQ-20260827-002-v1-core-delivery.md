# REQ-20260827-002 — V1 核心交付

**类型：** 功能 / 核心能力
**状态：** 本地实现完成 — 阶段 0–5 已结束；真实平台确认不列为开发阶段
**依据：** PRD §1–30；PDD §1–28

## 目标

在已经通过的 `appvar.other.read` POC 数据链路上交付 PRD 和 PDD 定义的 V1：当前用户 OIDC 会话、应用和实例发现、能力探测、ZIP 与 SQLite 一致性快照、计划与队列、备份库、校验、存储维护、告警，以及中英文正式界面。

## 已确认基础

- 当前用户应用目录、`appvar.other.read` 运行时投影、源解析、文件和数据库探测、SHA-256 与一次手动备份已由 POC 验证通过。
- V1 沿用 `/lzcapp/run/data/app/var` 和当前用户网盘写入路径，不为重做数据入口而改变已验证链路。
- POC 页面和 API 作为开发诊断资产保留，不进入生产导航和正式功能范围。

## 交付范围

1. OIDC、服务端会话，以及已登录业务请求的会话网关 UID/当前入口账户 UID 校验。
2. 每用户独立的控制库、应用目录同步、能力探测和正式领域 API。
3. ZIP 归档、SQLite Online Backup、manifest、校验和当前用户网盘存储。
4. 计划、批次、持久化队列、有界工作池、重试、补跑和保留策略。
5. 概览、应用、计划、任务、备份库、存储、告警和设置的正式页面及中英文文案。
6. 单实例共享风险提示、不可备份状态、审计和告警。

## SQLite 持续锁处理

目标 SQLite 的短暂 `BUSY`/`LOCKED` 继续在 30 秒窗口内由 Online Backup 重试。窗口耗尽时任务以 `SQLITE_SOURCE_LOCKED` 明确记录，页面提示用户暂停目标应用后重试；其他 SQLite 快照故障保持 `SQLITE_SNAPSHOT_FAILED`。备份应用不得自动停止、重启或写入目标应用，也不得把受锁 SQLite 降级为普通文件复制。

## 首个实现包

本轮交付阶段 1 与阶段 2 的前置闭环：服务端 OIDC、会话保存的网关 UID 与当前入口账户 UID 的业务请求校验、每用户 SQLite 控制库、当前用户应用目录同步、受限探测、OpenAPI 3.1 契约，以及应用资产柜和顶部会话信息的同源 API 对接。ZIP、SQLite Online Backup、网盘写入、计划、任务、快照和告警继续留在后续阶段；前端不得用本地定时器伪造这些操作。

首包正式接口为：`GET /api/session`、`POST /auth/logout`、`GET /api/applications`、`GET /api/applications/{appid}`、`GET /api/instances/{deploy_id}`、`POST /api/applications/sync` 与 `POST /api/instances/{deploy_id}/probe`。列表返回已持久化结果和同步状态；同步与重新检测返回 `202`，浏览器轮询列表直到同步结束。浏览器传入的实例 ID 必须在当前租户目录中存在，缺失或跨租户记录统一返回 `404`。

## 当前阶段：手动备份最小闭环

本轮开始阶段 3，只交付单个当前租户实例的手动备份闭环：`POST /api/instances/{deploy_id}/backup` 创建受限后台作业；服务再次确认该实例、源映射与完整预检，普通文件流式写入 ZIP，SQLite 使用 Online Backup API 生成临时一致性副本，随后写入 ZIP 内外 manifest、计算 SHA-256，并把完成快照原子提交到当前用户的 `MimiAppBakcup/<deploy_id>/<时间>/` 网盘目录。单实例目标必须显式确认共享数据风险；无数据、阻断数据库和无效实例不能创建快照。

本阶段同时提供当前租户的手动作业状态、快照列表/详情与快速校验接口，供应用页立即备份和备份库最小视图使用。API 只返回快照相对路径和安全元数据，不返回源绝对路径、其他用户数据、Token 或 Cookie。计划、通用持久化队列、批量备份、重试、补跑、保留、删除、导出和 SSE 继续留在阶段 4。

本地实现已完成，包含 ZIP 内 `appvar/`、内部 manifest、文件索引和 warnings，外部 manifest 的最后写入、SHA-256 快速校验、失败快照清理和控制库记录。当前用户网盘真实写入、会话网关 UID/入口账户 UID 校验和 A/B 用户快照隔离仍需在懒猫设备完成验收。

## 本轮阶段：计划、持久队列与备份库维护

本轮实现阶段 4。服务端把手动备份和计划触发统一收敛到当前租户的持久化批次与任务队列：计划支持显式实例目标与当前用户未来新增的可备份实例、每小时/每天/每周/五段 Cron、时区、暂停、立即运行、补跑窗口、有限重试和退避。批次使用 `tenant_uid + plan_id + scheduled_at` 幂等键；任务使用 `batch_id + deploy_id` 幂等键，并保存租约、心跳、尝试记录和实例级并发锁。

备份库补齐当前用户范围内的文件索引读取、完整校验、导出到 `_restore_exports/`、移入 `_trash/`、过期部分目录/回收站清理、快照与 manifest 对账及保留执行。删除、导出和维护只接受已由控制库按当前租户确认的快照 ID，存储模块仍只使用 `MimiAppBakcup/` 下的安全相对路径。校验异常暂停自动清理，至少保留一份已验证快照。

本轮不实现跨用户调度、目标应用写入、恢复到 appvar、外部网盘、告警/SSE/通知和完整页面国际化；这些留给阶段 5。真实设备仍需要补齐身份三方一致性、A/B 隔离、用户网盘写入与后台自启动/补跑证据。

## 本轮阶段：正式界面、运营能力与国际化

本轮实现阶段 5。用户可通过正式页面完成首次使用检查、查看概览、创建和编辑计划、查看批次与任务详情、浏览快照/文件索引、维护存储、阅读和处理告警、调整当前用户安全设置。概览、告警、设置、审计和实时刷新均使用当前租户的正式 API；前端不生成任务成功、进度、告警或配置变更的模拟结果。

服务端在每个用户独立的控制库中保存告警、设置、审计和事件序列。SSE 仅发送当前租户的聚合业务更新，断线后仍以 REST 接口重读权威状态。界面提供 `zh-CN` 和 `en-US` 文案，按稳定错误码显示安全提示；语言切换不提交用户、租户、源目录、Cookie 或 Token。

本轮不将可选 `user.notify` 视为已验证通知能力，不增加管理员视图、跨用户审计、外部通知、直接恢复、目标应用写入或未被执行引擎采用的伪设置。SSE、可选通知权限、OIDC 回调与网关 UID 会话绑定、A/B 隔离、当前用户网盘写入和后台补跑仍须在真实设备验收。

阶段 5 已完成本地实现：控制库迁移新增当前租户的告警、设置、审计和事件序列；概览、告警、设置、审计和限时 SSE 已通过正式 API 提供。任务和批次状态、快照校验与存储维护会写入审计或事件；最终失败任务会生成站内告警。八个主菜单、首次使用页、计划编辑、任务和批次详情、快照和文件索引、存储维护、告警处理及设置均已改为读取或调用正式 API，并提供 `zh-CN`、`en-US` 文案和失效会话跳转。

阶段 5 的最新源代码尚未重新执行 Go 服务端和 Vite 前端构建检查。构建通过后可按用户指令进入 LPK 打包。OIDC 回调与网关 UID 会话绑定、A/B 用户目录/API/快照隔离、当前用户网盘写入、后台启动和补跑属于真实平台外部确认，不单列为开发阶段。

## 本次登录体验修复

无会话访问会进入同源 OIDC 登录页。只有用户点击登录按钮时，服务端才创建 PKCE 登录事务并跳转懒猫授权；回调通过后固定进入首页。回调把 `X-HC-User-ID` 保存为会话网关 UID。旧 Cookie 的网关 UID 与当前 Header 不一致时，服务端删除会话和 Cookie，再让浏览器回到登录页重新授权；API 返回 `IDENTITY_MISMATCH` 403。OIDC `preferred_username` 不参与该相等判断。

本次范围不改变多实例租户边界、OIDC Claim 来源、`appvar.other.read` 入口或当前用户网盘写入路径。真实设备仍需验证完整的授权回调与网关 UID 会话绑定，构建检查不能替代该平台证据。

## 本次运行界面与备份流程修复

本次修复以已登录当前租户的正式页面为范围。应用详情只保留一处包标识符，使用懒猫 SDK 目录返回的应用图标；详情内同时展示该实例已发生的任务记录和由计划推导的下一次执行，不把查看任务与创建备份混在一起。单实例仍展示共享数据风险，但查看详情、立即备份和创建计划均不要求额外勾选确认。

页面初始化分别保存会话、设置和各业务资源的成功结果；某个无关接口失败不得让侧栏和设置页把已登录状态误报为“正在读取”。概览和存储页复用同一张卡片边框与间距令牌，所有页面的下拉选择统一使用已有的基础 Dropdown 组件。

手动备份在完成请求校验后使用不随浏览器断开取消的入队上下文，后台 worker 继续运行在独立上下文中。此处不放宽实例、租户、源目录或网盘路径校验，也不增加跨用户权限。正式应用入口子域名使用 `mimi-app-backup`，POC 使用 `mimi-app-backup-poc`；内部服务路由仍为 `web.mimi-app-backup.lzcapp:8080`。

本地验收仅包括 Go 服务端、Vite 前端与 LPK 构建/lint。真实设备仍需复现确认浏览器/网关取消时手动入队保持成功，以及图标 URL、OIDC 回调、用户隔离和网盘写入在平台上正确工作。
