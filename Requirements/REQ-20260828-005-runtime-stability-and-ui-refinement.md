# REQ-20260828-005 — 运行稳定性与界面细化

**类型：** 缺陷修复 / 功能与体验改进  
**状态：** 本地实现与构建检查完成；真实平台验证待执行  
**来源：** 2026-08-28 用户反馈  
**进度记录：** `Progress/PROG-REQ-20260828-005-runtime-stability-and-ui-refinement.md`

## 目标与验收

1. 前端只维护一条 SSE 订阅；事件突发时合并刷新，组件重渲染、会话对象更新或关闭抽屉不得反复中断并重建连接。断线以有退避的单次重连处理，不并发刷新全页数据。
2. 应用列表的“立即备份”先展示确认弹窗；不可备份实例仍展示该操作图标，但保持禁用。应用详情弹窗仅保留详情与历史，不再提供重新检测或立即备份操作。状态标签同时使用形象图标和文字。
3. 概览“下一批计划”和“风险提醒”卡片的内部条目具有明确的纵向间距。
4. 移除生产页面顶部栏；账户改为侧栏紧凑信息，语言切换移入侧栏；不再展示“OIDC、入口 Header 与应用 tenant 已校验”以及权限投影说明文字。
5. 网盘目录使用设置时区下的可读时间字符串，并在目录名中包含时区标识；所有前端日期按当前设置时区格式化并标示时区。
6. 设置页按现有视觉令牌重构为清晰的分区布局，仍只编辑已由服务端使用的语言、时区、补跑、重试、保留和站内通知偏好。
7. 备份库列表仅保留查看详情操作；快速校验仍可在快照详情中执行。
8. 备份库详情、任务中心和存储页使用当前产品视觉令牌重排：详情按快照概况、完整性、目录和文件组织；任务中心先展示队列概况与可点入的批次进度；存储页将容量、最近校验和维护项置于同一工作区。
9. 批次“查看”按批次 ID 请求详情，不再通过列表分页查找；生产页面中原生下拉统一封装在基础 `Dropdown` 内。
10. 计划编辑支持搜索可备份应用、带应用图标的多选、已选目标的可见摘要，以及小时/每天/每周/高级 Cron 的分层选择；保留与重试收起为高级设置。
11. 设置页采用目录式双栏布局：左侧分类入口，右侧按分类列出可操作条目；进入条目后只展示对应的真实设置和保存操作，保留账户、语言、时区、通知、调度、保留和审计的既有边界。
12. 所有主页面标题区域不展示环境或 tenant 英文 eyebrow；侧边栏不提供语言选择，页面语言仅在设置页的“外观”条目内使用基础 `Dropdown` 修改并保存。
13. 当前用户网盘备份根目录统一使用 `MimiAppBakcup`，不再以平台品牌命名；服务不迁移、合并或修改旧目录。
14. 备份库详情先读取控制库中的快照元数据；文件索引读取失败不得阻断详情弹窗打开。
15. 计划和设置中的保留数量、回收站宽限期、重试次数及重试间隔必须在字段下说明实际生效行为；移除不承载决策信息的流程性提示。
16. 移除“未来新增的可备份应用”动态目标。新建和编辑计划只允许搜索、查看图标并显式多选当前可备份应用；升级时旧动态计划必须停用，不能再自动入队。
17. 计划弹窗将保留策略和自动重试常驻展示在“高级选项”区，不使用折叠；每天和每周计划可选择本地执行时间；补跑改为“错过后不跑”开关。
18. 概览在单列布局下，“下一批计划”和“风险提醒”两张卡片之间始终保留清晰的纵向间距，不能贴合。
19. 设置目录的“备份偏好”与“维护与记录”必须展示不同内容：前者进入备份调度和保留设置，后者只展示审计记录。
20. 概览“下一批计划”和“风险提醒”的条目仅由明确的列表间距控制；计划时间不使用浏览器默认段落外边距，条目不设置额外最小高度，避免卡片出现无意义的大块留白。
21. 应用列表只保留“查看详情”入口；查看任务和查看快照入口收纳到应用详情弹窗中。
22. 立即备份确认弹窗的主操作文案统一为“立即备份”，不使用“立即入队”。
23. 从单个应用行或应用详情弹窗创建计划时，计划目标固定为当前应用；批量创建计划入口继续允许显式多选。
24. 设置账户页移除“重新验证会话”和管理员能力卡片；设置目录只在左侧显示，移动端保持可滚动可见。
25. 数据库检测标签对 SQLite 与未知数据库使用明确的本地化名称，并在详情中说明未知数据库通常是数据库后缀文件但未通过 SQLite 格式头校验。
26. 应用页点击“重新扫描全部”并在服务端接受刷新请求后，显示中英文一致的站内提示，明确告知应用目录刷新已提交且正在同步。
27. 侧边栏应用、计划、任务、备份库和告警徽标显示当前租户对应页面的总数，不受当前列表分页或已加载页数量影响。
28. 首次进入应用时，在应用目录同步和首屏应用数据准备期间显示克制的全局 loading；应用数据首次准备完成后显示一次全局中英文提示，加载期间不得把暂未返回的应用列表误显示为“没有找到匹配的应用实例”。
29. 任务中心只展示服务端提供的备份批次和任务历史；移除无用户侧 API 支持的队列概况、排队筛选和暂停/恢复操作。任务、批次、备份库和告警分页资源维护独立 loading，切换页面时未返回的数据展示页面级 loading，并优先读取用户常切换的资源。
30. 应用页面的数据概览分行显示文件数量与 SQLite 数量；只有检测到至少一个 SQLite 时才显示 SQLite 行。
31. 备份库应用标记复用当前租户应用目录按 `deployId` 返回的真实图标，不能使用页面自造的应用图形代替。
32. 任务中心移除“最近备份批次”展示组件，仅保留任务历史与服务端状态筛选。
33. 备份库快照的保留文案使用“保留中”和“已移入回收站”等生命周期表达，不使用“已启用/未启用”的开关状态表达。
34. 备份快照使用 `MimiAppBakcup/<deploy_id>/<时间>/` 目录结构；同一实例的时间目录冲突时追加批次短 ID，快照元数据、文件索引和一致性校验均使用提交后保存的相对路径。

## 边界与验证

- 不改变 OIDC、当前 tenant、`appvar.other.read`、目标数据只读或当前用户网盘写入边界。
- 确认弹窗是浏览器交互保护，不改变服务端已完成的实例、租户和源路径校验。
- 本地仅执行 Go 服务端构建与 Vite 前端构建；不新增或运行测试。真实懒猫环境仍需观察代理取消日志和网盘目录时区结果。
