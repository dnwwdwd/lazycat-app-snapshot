# REQ-20260831-009 — 选择范围文件树与应用元数据展示

**类型：** 功能与体验改进
**状态：** 本地实现完成；真实懒猫验证待执行
**来源：** 2026-08-31 用户反馈

## 目标

- 自定义备份范围用可展开的文件树展示目录和文件；选择目录时递归覆盖后代对象，SQLite/`.db` 文件使用数据库图标。
- 任务中心、计划列表/详情、备份库和详情统一显示应用名称与真实目录图标，并以 `deployId` 作为关联键。
- 计划详情显示“全量备份”或“自定义备份范围”，自定义范围沿用向导文件树视觉语言。
- 应用目录缺少商店标题或图标时，使用包标识符的可读降级名称和平台系统图标 URL；不能伪造应用图标。

## 边界

- 服务端仍只持久化和校验安全相对路径；目录递归语义由现有范围校验执行。
- 计划目标、任务和快照的名称/图标是当前租户目录的展示元数据，不改变目标数据、OIDC 或 `appvar` 隔离边界。
- 目录树继续受服务端游标分页和当前用户源目录约束；未获得平台图标时最终回退为首字母标识。

## 验收

1. 自定义范围目录树可展开，目录选择后其后代目录/文件呈递归选中状态，`.db` 文件显示数据库图标。
2. 任务中心第一列标题为“应用”，行内显示应用图标、名称和 `deployId`。
3. 计划详情每个目标显示应用图标/名称、全量或自定义文案，并以文件树显示自定义目录和文件。
4. 计划卡目标实例使用稍大的真实应用图标；未上架应用不再拼接无效图标地址，平台目录缺失时有可读降级。

## 本地验证与待补证据

- 仅执行 Go 编译、OpenAPI 类型生成、Vite 生产构建和 `git diff --check`。
- 真实设备仍需确认 `/sys/icons` 对未上架应用的可访问性、目录树分页以及不同用户的应用元数据隔离。
